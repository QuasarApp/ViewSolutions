Detailed Description

The ViewSolutions namespace.

This namespace groups all C++ classes of the ViewSolutions module: the model system (ModelStorage, iModel, BaseListModel, BaseHashModel), the notification system (NotificationService, NotificationData, HistoryNotificationsModel) and helper classes such as ColorPicker, QMLColorPicker and AvatarGenerator.

Example:

#include <viewsolutions.h>
int main(int argc, char *argv[])
{
QGuiApplication app(argc, argv);
QQmlApplicationEngine engine;
// Imports all QML resources and creates the central model storage.
auto models = ViewSolutions::init(&engine);
if (!models)
return -1;
engine.load(QUrl("qrc:/main.qml"));
return app.exec();
}

nodiscard

init this method import all qml resources to your project and creates the central model storage of the application.

The returned ModelStorage object is exposed to QML as the modelsStorage context property.

Parameters
engineis QQmlApplicationEngine object.
Returns
gui model storage object. nullptr is returned if the engine or its root context is invalid.

Example:

QSharedPointer<ViewSolutions::ModelStorage> models = ViewSolutions::init(&engine);
// Access a model from C++ (the color picker is registered by init):
auto picker = models->get<ViewSolutions::QMLColorPicker>("ColorPicker");
