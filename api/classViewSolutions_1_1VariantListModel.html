Detailed Description

The VariantListModel class is universal implementation for all atomic types.

The model is a BaseListModel<QVariant> and can store any QVariant value (int, double, QString, QObject, ...).

Example:

ViewSolutions::VariantListModel model;
QList<QVariant> items;
items << "one" << 2 << 3.14;
model.setDataList(items);
