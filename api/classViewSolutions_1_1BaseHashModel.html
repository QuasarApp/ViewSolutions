Detailed Description

template<class KEY, class DATA>
class ViewSolutions::BaseHashModel< KEY, DATA >

The BaseHashModel class is the base class of all GUI hash models.

A BaseHashModel stores its items in a hash table and exposes them to QML as a list model. Every item can be accessed by a unique key.

Template Parameters
KEY- is type of hash table key,
DATA- is main stored delegate model of all list items.

Concepts and usage rules:

  • All models should provide delegate models based on QObject
  • If the model requires a fast solution, just implement a BaseListModel<T> model instead
Note
To access the delegate model use the Qt::EditRole role: it is available in QML by the delegateModel keyword.
The BaseHashModel does not support the QML space directly, for short access in QML use the BaseListModel instead.

Example of a model based on the BaseHashModel:

class IntStringModel: public ViewSolutions::BaseHashModel<int, QString>
{
Q_OBJECT
public:
IntStringModel(QObject* parent = nullptr):
ViewSolutions::BaseHashModel<int, QString>(parent) {}
};
