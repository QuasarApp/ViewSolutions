Detailed Description

template<class TYPE>
class ViewSolutions::BaseListModel< TYPE >

The BaseListModel class is the base class of all GUI list models.

A BaseListModel stores its items in a simple list and exposes them to QML as a list model. The list of all items is also available in QML through the listDate property (see the BASE_LIST_MODEL_DATA_PROPERTY macro).

Template Parameters
TYPE- is main stored delegate model of all list items.

Concepts and usage rules:

  • All models should provide delegate models based on QObject
  • If the model requires a fast solution, just implement a BaseListModel<int> model
Note
To access the delegate model use the Qt::EditRole role: it is available in QML by the delegateModel keyword.

Example of a model based on the BaseListModel:

class VariantListModel: public ViewSolutions::BaseListModel<QVariant>
{
Q_OBJECT
BASE_LIST_MODEL_DATA_PROPERTY(QVariant)
public:
VariantListModel(QObject* ptr = nullptr):
ViewSolutions::BaseListModel<QVariant>(ptr) {}
};
