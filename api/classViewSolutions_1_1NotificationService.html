Detailed Description

The NotificationService class. This class used for working with notify.

This service displays notifications and questions on the main application window and stores all sent notifications in a history model (see HistoryNotificationsModel).

The service is a singleton - use the getService method to access it.

Example:

// Show a notification:
ViewSolutions::NotificationService::getService()->setNotify("Title", "Message");
// Ask a question and wait for the user answer:
ViewSolutions::NotificationService::getService()->setQuestion(
[](bool accept) {
if (accept)
qDebug() << "User accepted";
},
"Are you sure?");
