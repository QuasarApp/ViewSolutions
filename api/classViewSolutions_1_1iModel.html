Detailed Description

The iModel class is base model for GUI models. Works with ModelStorage. All models after adding can get access to any othe models that located on same storage object.

To create a new model implement the iModel interface. Every model must provide a unique model id with the modelId method.

Example:

class MyModel: public QObject, public ViewSolutions::iModel
{
Q_OBJECT
public:
explicit MyModel(): QObject() {}
// iModel interface
QString modelId() const override { return "myModel"; }
};
