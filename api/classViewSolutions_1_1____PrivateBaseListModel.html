Detailed Description

The __PrivateBaseListModel class is the private QObject base class of the BaseListModel template.

This class is not intended to be used directly. It exists only to make the Q_OBJECT macro (and its signals) available to the BaseListModel template class, which cannot use Q_OBJECT itself.
