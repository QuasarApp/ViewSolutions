#define VIEWSOLUTION_EXPORT   Q_DECL_IMPORT

VIEWSOLUTION_EXPORT marks a symbol as part of the public ViewSolutions API.

When the ViewSolutions shared library is built (VIEW_SOLUTIONS_LIBRARY is defined) the macro expands to Q_DECL_EXPORT, otherwise to Q_DECL_IMPORT for consuming applications.

Example:

class VIEWSOLUTION_EXPORT ColorPicker
{
public:
explicit ColorPicker();
};
